# SkillMatrix Help & Reference Guide

### Quick Start Checklist
1. Ensure MySQL is running on `localhost:3306`.
2. Configure password in `src/main/resources/application.properties`.
3. Run `mvn spring-boot:run` or open in IntelliJ IDEA and run `SkillMatrixApplication.java`.
4. Open `http://localhost:8080/index.html` in your browser.
